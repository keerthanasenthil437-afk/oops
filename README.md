# 🧠 Java GUI OOPs Projects

This repository contains Object-Oriented Programming projects developed using Java with GUI (Swing/AWT).

---

## 📌 Projects Included

### 🛒 Shopping Cart Application
- Add and remove products
- View total price
- Simple cart system using GUI

### 🧠 Quiz Application
- Multiple choice questions
- Score calculation
- Interactive GUI interface

## 🛠️ Technologies Used

- Swing (GUI)
- AWT
- Object-Oriented Programming (OOPs)

## 🎯 Concepts Used
- Classes & Objects
- Inheritance
- Encapsulation
- Polymorphism
- Event Handling (GUI)

2. Compile the Java files
